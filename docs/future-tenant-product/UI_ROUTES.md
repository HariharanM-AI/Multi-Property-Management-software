# Future Tenant Product — UI Routes & Screen Blueprints

This document outlines the recommended screen hierarchy for the mobile-first **Phase 2 Tenant Application**:

### Core Navigation Tabs
1. **Home (`/`)**: Active stay card (bed/room number, property address), current rent due card, quick actions (Pay Rent, Report Issue, Add Visitor).
2. **Payments (`/payments`)**: Invoices list, unpaid balances, payment history, downloadable PDF receipts.
3. **Services & Maintenance (`/helpdesk`)**: New ticket submission, active repair progress tracker, facility service booking.
4. **Community (`/community`)**: Property notice stream, pinned house rules, resident discussions, lost & found.
5. **Marketplace (`/marketplace`)**: Resident second-hand goods board, post creation modal, item reservation.
6. **Profile & Documents (`/profile`)**: Digital agreements, verified KYC proofs, deposit refund status, emergency contacts.
